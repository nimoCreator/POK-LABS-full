# Zadanie pmkzad01

## Tresc zadania

Nalezy uruchomic program modelujacy uklad elektryczny `RC` i narysowac wykres funkcji ladunku od czasu dla rozwiazania analitycznego oraz rozwiazan numerycznych.

## Analiza polecenia

Badane rownanie ma postac:

dq/dt = -q

przy warunku poczatkowym `q(0) = 1`. Rozwiazanie analityczne jest rowne:

q(t) = exp(-t)

W programie porownano trzy schematy numeryczne:

1. metode Eulera,
2. metode punktu srodkowego,
3. metode Rungego-Kutty czwartego rzedu.

Do przykladowego porownania przyjeto:

- `dt = 0.1`
- `t_k = 4.0`

## Kod

Najwazniejszy fragment odpowiedzialny za krok Rungego-Kutty:

real RCRungeKuttaStep(real q, real delt)
{
    real k1 = -delt * q;
    real k2 = -delt * (q + 0.5L * k1);
    real k3 = -delt * (q + 0.5L * k2);
    real k4 = -delt * (q + k3);
    return q + (k1 + 2.0L * k2 + 2.0L * k3 + k4) / 6.0L;
}

# Zadanie pmkzad02

## Tresc zadania

Nalezy uzupelnic model prostego wahadla, uruchomic program i porownac przebieg kata wychylenia z przyblizonym rozwiazaniem analitycznym oraz z metodami numerycznymi.

## Analiza polecenia

Model wahadla opisuje uklad dwoch rownan pierwszego rzedu:

- `d(fi)/dt = om`
- `d(om)/dt = -(g/l) * sin(fi)`

W odroznieniu od surowego pliku cwiczeniowego rozwiazanie zostalo uporzadkowane tak, aby wszystkie trzy metody aktualizowaly jednoczesnie kat i predkosc katowa. Dla porownania z rozwiazaniem analitycznym przyjeto maly kat poczatkowy, bo wzor:

fi(t) = fi0 * cos(t * sqrt(g/l))

jest przyblizeniem poprawnym glownie dla niewielkich wychylen.

W przykladowych wynikach uzyto parametrow:

- `l = 1.2 m`
- `fi0 = 5 deg`
- `dt = 0.02 T`
- `t_k = 3 T`

gdzie `T = 2*pi*sqrt(l/g) = 2.197536 s`.

## Kod

Najwazniejszy fragment dla kroku Rungego-Kutty:

PendulumState RungeKuttaStep(const PendulumState& state, real delt, real g_div_l)
{
    PendulumState k1 = Derivatives(state, g_div_l);
    PendulumState s2 { state.fi + 0.5L * delt * k1.fi, state.om + 0.5L * delt * k1.om };
    PendulumState k2 = Derivatives(s2, g_div_l);
    PendulumState s3 { state.fi + 0.5L * delt * k2.fi, state.om + 0.5L * delt * k2.om };
    PendulumState k3 = Derivatives(s3, g_div_l);
    PendulumState s4 { state.fi + delt * k3.fi, state.om + delt * k3.om };
    PendulumState k4 = Derivatives(s4, g_div_l);

    return
    {
        state.fi + delt * (k1.fi + 2.0L * k2.fi + 2.0L * k3.fi + k4.fi) / 6.0L,
        state.om + delt * (k1.om + 2.0L * k2.om + 2.0L * k3.om + k4.om) / 6.0L
    };
}

# Zadanie mdkzad01

## Tresc zadania

Nalezy zaimplementowac model obwodu `RLC` z wykorzystaniem metody Rungego-Kutty i otrzymac przebiegi dla kilku zestawow parametrow oraz kilku sygnalow wejsciowych.

## Analiza polecenia

W programie jako zmienne stanu przyjeto:

- prad `i(t)` w obwodzie,
- napiecie `uC(t)` na kondensatorze.

Otrzymany uklad rownan ma postac:

- `di/dt = (u_we(t) - R*i - uC) / L`
- `duC/dt = i / C`

Program w katalogu `POK-6/POK 6/MDK` realizuje schemat Rungego-Kutty czwartego rzedu i generuje trzy przebiegi:

1. sygnal sinusoidalny,
2. skok napiecia stalego,
3. impuls prostokatny.

## Kod

Najwazniejszy fragment wyznaczajacy pochodne stanu:

private static RlcState Derivative(RlcState state, double timeSeconds, CircuitParameters parameters, InputSignal signal)
{
    double sourceVoltage = signal(timeSeconds);
    double di = (sourceVoltage - parameters.ResistanceOhms * state.Current - state.CapacitorVoltage)
        / parameters.InductanceHenries;
    double du = state.Current / parameters.CapacitanceFarads;
    return new RlcState(di, du);
}

# Podsumowanie

Laboratorium 6 laczylo klasyczne modele fizyczne z implementacja metod numerycznych. W czesci `PMK` najlepiej wypadla metoda Rungego-Kutty, zarowno dla prostego ukladu `RC`, jak i dla modelu wahadla. W czesci `MDK` udalo sie przygotowac w pelni uruchamialny model `RLC` z kilkoma wariantami wymuszenia.

Najwazniejszy wniosek z calego laboratorium jest taki, ze wraz ze wzrostem zlozonosci modelu rosnie znaczenie poprawnego doboru metody numerycznej i kroku czasu. Proste metody, takie jak Euler, wystarczaja do orientacyjnego przebiegu, ale dopiero metody wyzszego rzedu pozwalaja zachowac wysoka zgodnosc z rozwiazaniem wzorcowym lub fizycznie oczekiwanym zachowaniem ukladu.
