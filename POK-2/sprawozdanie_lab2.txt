# Wprowadzenie

Rozwiązania są przygotowane w formie potomków interface'u IZadanie, który odpowiada za uruchamianie zadań, przygotowanie Writer'a wypisującego wyniki do pliku i/lub konsoli oraz pomiar czasu pracy programu. # Zadanie moA06zad1

## Treść zadania

W poleceniu mamy napisać program, który pobiera rząd n układu równań liniowych oraz wszystkie stałe współczynniki, czyli macierz A i wektor b. Następnie program rozwiązuje układ metodą eliminacji Gaussa, sprawdza, czy rozwiązanie istnieje, a jeżeli tak, wypisuje niewiadome x oraz względne błędy otrzymane po podstawieniu rozwiązania do równania.

## Analiza polecenia

Do rozwiązania układu A*x=b zastosowano eliminację Gaussa z wyborem elementu podstawowego w bieżącej kolumnie. Macierz A i wektor b są przepisywane do macierzy rozszerzonej, następnie wykonywane jest zerowanie elementów pod diagonalą. Po otrzymaniu postaci trójkątnej program wyznacza niewiadome przez podstawianie wsteczne. Na końcu obliczany jest wektor błędów względnych db, który pozwala sprawdzić dokładność wyniku.

## Kod

public void Run(TextWriter writer)
{
    int n = _b.Length;

    writer.WriteLine("rzad ukladu n = {0}\n", n);
    writer.WriteLine("macierz A oraz wektor b:");
    for (int i = 0; i < n; i++)
    {
        writer.Write("|");
        for (int j = 0; j < n; j++)
        {
            writer.Write(" {0,10:f6}", _a[i, j]);

    }

    {
        writer.WriteLine("| {0,3} | {1,16:g12} | {2,13:e6} |",
            i + 1, result.X[i], result.Db[i]);
    }
}

Najważniejszy fragment metody Gaussa:

for (int k = 0; k < n - 1; k++)
{
    double maxElement = Math.Abs(c[k][k]);
    int maxPosition = k;

    for (int i = k + 1; i < n; i++)
    {
        double element = Math.Abs(c[i][k]);
        if (element > maxElement)
        {
            maxElement = element;
            maxPosition = i;
        }
    }

    if (Math.Abs(maxElement) < Eps)
    {
        return new LinearEquationResult(false, x, db);
    }

    if (maxPosition != k)
    {
        (c[k], c[maxPosition]) = (c[maxPosition], c[k]);
    }

    double ckk = c[k][k];
    for (int i = k + 1; i < n; i++)
    {
        double multiplier = c[i][k] / ckk;
        c[i][k] = 0.0;

        for (int j = k + 1; j <= n; j++)
        {
            c[i][j] -= multiplier * c[k][j];
        }
    }
}

# Zadanie moA06zad2

## Treść zadania

W poleceniu mamy napisać program, który w pętli o m krokach generuje losowo w przedziale 0..10 wszystkie współczynniki układu równań liniowych dowolnego rzędu n. Następnie każdy układ jest rozwiązywany metodą eliminacji Gaussa. Program zlicza przypadki, w których rozwiązanie istnieje, oraz oblicza uśrednione błędy względne.

## Analiza polecenia

Zadanie sprawdza praktyczną dokładność metody eliminacji Gaussa na wielu losowych układach równań. Dla każdego przypadku generowana jest nowa macierz A i nowy wektor b, a potem wywoływany jest ten sam solver co w poprzednim zadaniu. Jeżeli układ ma jednoznaczne rozwiązanie, program dolicza jego błędy db do sumy i aktualizuje największy odnotowany błąd.

## Kod

public void Run(TextWriter writer)
{
    var random = new Random(_seed);
    int solutionCount = 0;
    double errorSum = 0.0;
    double maxError = 0.0;

    for (int step = 0; step < _m; step++)
    {
        var equation = GaussSolver.CreateRandomEquation(_n, random);
        var result = GaussSolver.Solve(equation.A, equation.B);

        if (!result.HasSolution)
        {
            continue;
        }

        solutionCount++;
        foreach (double db in result.Db)
        {
            double error = Math.Abs(db);
            errorSum += error;
            maxError = Math.Max(maxError, error);
        }
    }

    double averageError = solutionCount == 0
        ? 0.0
        : errorSum / (solutionCount * _n);

    writer.WriteLine("liczba przypadkow z rozwiazaniem = {0}", solutionCount);
    writer.WriteLine("sredni blad wzgledny db = {0:e6}", averageError);
    writer.WriteLine("maksymalny blad wzgledny db = {0:e6}", maxError);
}

# Zadanie moA06zad3

## Treść zadania

W poleceniu mamy napisać program, który dla kolejnych rzędów układu n = 2..N mierzy czas działania metody eliminacji Gaussa. Dla każdego n program w dodatkowej pętli wykonuje m losowych układów, rozwiązuje je metodą Gaussa, sprawdza istnienie rozwiązania i na końcu zapisuje średni czas rozwiązania do pliku tekstowego CSV. Otrzymane dane mogą zostać użyte do wykonania wykresu w programie Excel.

## Analiza polecenia

Celem zadania jest empiryczne wyznaczenie charakteru złożoności obliczeniowej metody eliminacji Gaussa. Teoretycznie metoda ma złożoność O(n^3), ponieważ główna część algorytmu zawiera zagnieżdżone pętle zależne od rozmiaru macierzy. Program mierzy średni czas dla wielu losowych układów, co zmniejsza wpływ pojedynczych odchyleń pomiarowych. W wynikach widać lokalne wahania, ale ogólny trend czasu rośnie razem z rzędem układu.

## Kod

public void Run(TextWriter writer)
{
    var random = new Random(_seed);

    writer.WriteLine("N = {0}  m = {1}  seed = {2}\n", _nMax, _m, _seed);
    writer.WriteLine("n;czas_ms;");

    for (int n = 2; n <= _nMax; n++)
    {
        int solutionCount = 0;
        var stopwatch = Stopwatch.StartNew();

        for (int step = 0; step < _m; step++)
        {
            var equation = GaussSolver.CreateRandomEquation(n, random);
            var result = GaussSolver.Solve(equation.A, equation.B);
            if (result.HasSolution)
            {
                solutionCount++;
            }
        }

        stopwatch.Stop();

        double averageTime = solutionCount == 0
            ? 0.0
            : stopwatch.Elapsed.TotalMilliseconds / solutionCount;

        writer.WriteLine("{0};{1:f6}", n, averageTime);
    }
}

## Analiza polecenia

Metoda bisekcji polega na kolejnym połowieniu przedziału i wyborze tej części, w której występuje zmiana znaku funkcji. W programie dla każdego kroku obliczany jest środek x = (a + b) / 2 oraz wartość f(x). Następnie aktualizowany jest jeden z końców przedziału. Dla równania tan^3(x) - 4*tan(x) = 0 w badanym zakresie znalezione rozwiązanie odpowiada wartości x, dla której tan(x) = 2, czyli x jest bliskie 1.1071487178.

## Kod

public void Run(TextWriter writer)
{
    double a = _a;
    double b = _b;
    double x = double.NaN;

    for (int i = 1; i <= _n; i++)
    {
        x = 0.5 * (a + b);
        double fx = f(x);

        writer.WriteLine("| {0,3} | {1,14:f10} | {2,14:f10} | {3,14:f10} | {4,13:e6} |",
            i, a, b, x, fx);

        if (f(a) * fx <= 0.0)
        {
            b = x;
        }
        else
        {
            a = x;

    writer.WriteLine("f(x) = {0:e6}", f(x));
}

public double f(double x)
{
    double tan = Math.Tan(x);
    return tan * tan * tan - 4.0 * tan;
}

# Zadanie moA07zad2a

## Treść zadania

W poleceniu mamy napisać program, który metodą siecznych rozwiązuje równanie exp(x - 1) + x^2 - 2 = 0. W pierwszej wersji programu podawane są: początek a i koniec b przedziału oraz liczba n cięć przedziału sieczną.

## Analiza polecenia

Metoda siecznych wyznacza kolejne przybliżenie miejsca zerowego na podstawie prostej przechodzącej przez punkty (a, f(a)) oraz (b, f(b)). W implementacji prawy koniec b pozostaje stały, a lewy koniec a jest zastępowany przez kolejne przybliżenie x. Dla równania exp(x - 1) + x^2 - 2 = 0 rozwiązaniem jest x = 1, ponieważ exp(0) + 1 - 2 = 0.

## Kod

public void Run(TextWriter writer)
{
    double a = _a;
    double b = _b;
    double x = double.NaN;

    for (int i = 1; i <= _n; i++)
    {
        x = Secant(a, b);
        double fx = f(x);

        writer.WriteLine("| {0,3} | {1,14:f10} | {2,14:f10} | {3,14:f10} | {4,13:e6} |",
            i, a, b, x, fx);

        a = x;
    }

    writer.WriteLine("x({0}) = {1:g15}", _n, x);
    writer.WriteLine("f(x) = {0:e6}", f(x));
}

private static double Secant(double a, double b)
{
    double fa = f(a);
    double fb = f(b);

    return (a * fb - b * fa) / (fb - fa);
}

public static double f(double x)
{
    return Math.Exp(x - 1.0) + x * x - 2.0;
}

# Zadanie moA07zad3a

## Treść zadania

W poleceniu mamy napisać program, który metodą stycznych Newtona rozwiązuje równanie 2^(x^2 - 5*x + 10)*log(2)*(2*x - 5) = 0. W pierwszej wersji programu podawane są: początek a i koniec b przedziału oraz liczba n kroków iteracji.

## Analiza polecenia

Metoda Newtona korzysta z wartości funkcji i jej pochodnej. Kolejne przybliżenie wyznaczane jest ze wzoru x = x - f(x)/f'(x). Program rozpoczyna od środka przedziału [a, b], czyli od x = 3.0. Badane równanie ma pierwiastek w punkcie x = 2.5, ponieważ czynnik (2*x - 5) zeruje całą funkcję, a pozostałe czynniki są dodatnie.

## Kod

public void Run(TextWriter writer)
{
    double x = 0.5 * (_a + _b);

    writer.WriteLine("| {0,3} | {1,14} | {2,13} |", "i", "x", "f(x)");
    writer.WriteLine("| {0,3} | {1,14:f10} | {2,13:e6} |", 0, x, f(x));

    for (int i = 1; i <= _n; i++)
    {
        x -= f(x) / df(x);
        writer.WriteLine("| {0,3} | {1,14:f10} | {2,13:e6} |", i, x, f(x));
    }

    writer.WriteLine("x({0}) = {1:g15}", _n, x);
    writer.WriteLine("f(x) = {0:e6}", f(x));
}

public static double f(double x)
{
    double log2 = Math.Log(2.0);
    double p = x * x - 5.0 * x + 10.0;
    return Math.Pow(2.0, p) * log2 * (2.0 * x - 5.0);
}

public static double df(double x)
{
    double log2 = Math.Log(2.0);
    double p = x * x - 5.0 * x + 10.0;
    double n = 2.0 * x - 5.0;

    return log2 * Math.Pow(2.0, p) * (log2 * n * n + 2);
}

## Treść zadania

W drugiej wersji zadania z metodą Newtona procedurę iteracyjną należy przerwać po osiągnięciu podanej dokładności eps, poniżej której spada wartość bezwzględna lewej strony równania 2^(x^2 - 5*x + 10)*log(2)*(2*x - 5) = 0.

## Analiza polecenia

Wersja z kryterium dokładności wykonuje tę samą iterację Newtona, ale kończy działanie, kiedy |f(x)| <= eps. Ponieważ w tym równaniu metoda zbiega bardzo szybko do x = 2.5, program powinien wykonać tylko kilka kroków i zatrzymać się bez potrzeby narzucania stałej liczby iteracji.

## Kod

double x = 0.5 * (_a + _b);
double fx = f(x);
int i = 0;

while (Math.Abs(fx) > _eps && i < 1000)
{
    i++;
    x -= fx / df(x);
    fx = f(x);
    writer.WriteLine("| {0,3} | {1,14:f10} | {2,13:e6} |", i, x, fx);
}

writer.WriteLine("x = {0:g15}", x);
writer.WriteLine("f(x) = {0:e6}", fx);
writer.WriteLine("liczba krokow = {0}", i);

# Podsumowanie

W części dotyczącej układów równań liniowych metoda eliminacji Gaussa poprawnie wyznaczała rozwiązania oraz dawała bardzo małe błędy względne. Testy losowe dla n = 5 potwierdziły stabilność implementacji, a pomiar czasu dla n = 2..100 pokazał rosnący koszt obliczeń zgodny z charakterem złożoności O(n^3).

W części dotyczącej równań nieliniowych wszystkie badane metody doprowadziły do poprawnych miejsc zerowych. Bisekcja była stabilna, lecz wymagała większej liczby kroków. Metoda siecznych poprawnie znalazła rozwiązanie x = 1 dla równania exp(x - 1) + x^2 - 2 = 0. Metoda Newtona była najszybsza dla równania z zadania 3, ponieważ osiągnęła dokładny wynik x = 2.5 już po kilku iteracjach.
